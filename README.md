# the-novisurf-co

Landing page for Novisurf Co — the company behind [HeySurf](https://heysurf.dev).

Built with Next.js (App Router), [Geist](https://vercel.com/font) Sans for headings and Geist Serif for body copy.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run typecheck
```

- `app/page.tsx` — page content (hero, vision, team, contact, footer)
- `app/globals.css` — all styles
- `components/` — `Sidebar` (scroll-spy nav, mobile menu) and `Logo`
